## Description

The biopsion’s *[[Psychic Succor|Psychic Succor]]* now can be used as an On Turn power, albeit only once per round. By Committing an additional Effort for the day with each use, it can even be used as an Instant power, though it still can only be used once per round. Any surcharges for augmenting the succor apply normally, such as with *[[Tissue Integrity Field|Tissue Integrity Field]]*.
