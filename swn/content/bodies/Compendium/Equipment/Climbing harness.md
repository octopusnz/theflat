## Description

Climbing harness: A collection of straps, ropes, pitons, and other climbing aids that grant a +1 bonus on any [[Exert|Exert]] climbing skill test. Using a climbing harness is noisy, and any [[Sneak|Sneak]] skill checks while climbing with one suffer a -2 penalty.
